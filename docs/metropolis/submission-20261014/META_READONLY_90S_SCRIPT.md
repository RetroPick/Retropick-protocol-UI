# MetaMask read-only demo — editable human narration

Target: 90 seconds at natural pace. The delivered evidence film is silent. Read-aloud narration can be recorded separately without changing what the film proves.

## 0–10 seconds
RetroPick connects token launches to Kuru markets on Monad Testnet. This demonstration shows our MetaMask Agent Wallet plugin's public market intelligence.

## 10–25 seconds
The plugin was installed from our public Git branch using the actual Agent Wallet CLI. Inspection confirms version zero point one, and exactly three read commands. No wallet was provisioned.

## 25–45 seconds
First, markets reads the Coordinator ledger for our configured token. The chain reports phase two: graduated. It maps this token to the same Kuru market shown in our historical settlement evidence. This command lists the configured launch, rather than claiming universal market discovery.

## 45–65 seconds
Market inspect reads Kuru's best quoted bid and ask, and the chain's head block. These integer strings preserve precision. Quotes may include the vault's automated liquidity; they do not prove resting order depth or guarantee execution.

## 65–80 seconds
Market risk calculates a ninety-nine basis point quoted spread. Historical trades were not queried, so activity and staleness remain unknown. The output exposes that uncertainty instead of presenting a false healthy status.

## 80–90 seconds
This release supports discovery, inspection and risk. Signing, order placement and cancellation remain unimplemented. Sponsor qualification remains conditional on the required trading workflow.
